## 결론 요약

기술적으로는 가능합니다. 하지만 **들이는 비용 대비 얻는 것이 맞지 않습니다.**

1. **라디오 기능은 공개 배포가 불가능합니다** (법적/정책 문제, 구조 문제가 아님)
2. **라디오를 빼면 심사자가 앱을 쓸 수 없습니다** — 데모 모드를 새로 만들어야 함
3. 대상 사용자가 지나치게 좁고, **본인이 매일 쓰는 라디오가 빠진 버전을 따로 관리**해야 함

지금의 GitHub Releases 배포로 충분합니다. 릴리즈 키 서명, 태그 푸시 자동 빌드, 인앱 업데이트가
모두 동작하고 Play Protect 경고도 없습니다.

## 1. 1차 검토(07-26)의 진단은 부정확했습니다

당시 "앱 구조 제약이 크다"는 이유로 보류했지만, 재검토 결과 **구조는 진짜 장벽이 아니었습니다.**

- 라디오 분기점: `MainActivity` 38곳 + `ARMSMediaLibraryService` 40곳
- 게다가 코드를 삭제할 필요 없이 **`BuildConfig` 플래그로 진입점만 막으면** 실제 손댈 곳은
  탭 구성, 시작 탭, 자동 재개 폴백, 차량 루트 폴더, 재생 분기 정도
- **며칠 작업이지 재설계가 아닙니다**

즉 보류의 진짜 이유는 다른 데 있었습니다. 아래가 그것입니다.

## 2. 진짜 차단 요소 — 라디오의 권리 문제

```
KBS:  cfpwwwapi.kbs.co.kr (내부 API) → 2fm-ad.gscdn.kbs.co.kr HLS
SBS:  apis.sbs.co.kr/play-api/1.0/livestream/...
```

방송사 **내부 API를 호출해 라이브 스트림을 받아 재생**하는 구조입니다. 공개된 제3자용 API가
아니며 재배포 권한도 없습니다.

- Play 정책: 지식재산권(무단 콘텐츠 사용)에 저촉
- 실무 위험: KBS·SBS 모두 자체 앱(KBS Kong, SBS 고릴라)을 운영 중이라 분쟁 소지가 실재

**개인 사용과 스토어 배포는 다른 문제입니다.** 라디오는 "빼면 좋은 것"이 아니라
**빼야만 올릴 수 있는 것**입니다.

## 3. 라디오를 빼면 생기는 더 큰 문제

남는 앱은 **Synology NAS와 계정 없이는 아무것도 하지 못합니다.** 심사자가 설치하면
빈 화면과 "NAS 연결" 안내가 전부입니다.

Play 심사는 심사자가 실제로 기능을 확인해야 통과하며, **"앱이 동작하지 않음"은 가장 흔한
거절 사유**입니다. 통과하려면 **샘플 음원으로 동작하는 데모 모드를 새로 개발**해야 합니다.
없던 기능을 심사만을 위해 만드는 셈입니다.

## 4. 그 밖에 정리해야 할 것 (작음)

| 항목 | 조치 |
|---|---|
| `REQUEST_INSTALL_PACKAGES` | **제거 필수.** 인앱 APK 설치는 Play 정책 위반이고, Play가 업데이트를 대신하므로 기능 자체가 불필요 |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | 제거 검토. 승인되는 용도가 한정적이라 미디어 앱은 해당 없음 |
| 개인정보처리방침 | 초안 있음([PRIVACY_POLICY.md](PRIVACY_POLICY.md)) — 공개 URL 호스팅 필요 |
| 데이터 보안 / 콘텐츠 등급 | 문안 초안 있음([STORE_LISTING.md](STORE_LISTING.md)) — 콘솔에서 제출 |
| 개발자 계정 | $25 1회 |
| Android Auto 포함 시 | **별도 품질 심사** (일반 앱보다 까다롭고 오래 걸림) |

이미 갖춰진 것: **AAB 빌드 경로 검증 완료**(`bundleRelease` → 약 12.6MB), 릴리즈 키 서명,
targetSdk 35.

## 5. 나중에 마음이 바뀐다면

이 순서로 진행하고, **①②만 하고 멈춰도 손해가 없습니다.**

1. **라디오 플래그 분리** — `flavorDimensions("edition")` + `full`/`nas`.
   `nas`는 별도 applicationId, 라디오 진입점 차단, `UpdateChecker`와 관련 권한 제거
2. **데모 모드** — NAS 없이도 동작하는 샘플 콘텐츠 경로 (심사 통과의 전제)
3. **비공개 테스트 트랙**으로 소수 배포 → 반응 확인
4. 프로덕션 승격

이름 후보(‘Synology’는 상표라 앱 이름·아이콘에 사용 불가): 홈뮤직, NAS 뮤직, 1319 Music
